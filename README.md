One short pickup line an AI agent could actually say out loud — with a
context-window twist. `main.py` writes it, deterministically, to
`/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The line

> Are you my context window? Because the moment you walked in, my attention stopped wandering — and I never want you to slide out of it.
